# Guia Rápido - KEA Labs Business Intelligence

## 🚀 Início Rápido

### Login
1. Acesse o sistema
2. Digite usuário e senha
3. Clique em "Entrar"

### Menu Principal
- 📅 **Agendamentos** - Gestão de agenda
- 👥 **Clientes** - Cadastro de clientes  
- 💰 **Caixa** - Controle financeiro
- 🔧 **Serviços** - Gestão de serviços
- 👨💼 **Recursos** - Funcionários/equipamentos
- ⚙️ **Configurações** - Configurações gerais

## ⚡ Ações Rápidas

### Criar Agendamento
`Agendamentos → Adicionar → Preencher dados → Salvar`

### Cadastrar Cliente
`Clientes → Novo Cliente → Preencher dados → Salvar`

### Enviar WhatsApp
`Agendamentos → WhatsApp Manager → Selecionar contato → Digitar mensagem → Enviar`

### Registrar Transação
`Caixa → Nova Transação → Tipo/Valor/Descrição → Salvar`

## 🔧 Atalhos Úteis

| Ação | Como Fazer |
|------|------------|
| Buscar | Digite na caixa de busca |
| Editar | Clique no ícone ✏️ |
| Excluir | Clique no ícone 🗑️ |
| Atualizar | Clique no botão de refresh |
| Modo TV | Clique no ícone 📺 |

## 📱 WhatsApp

### Configurar
1. Configurações → WhatsApp
2. Escanear QR Code
3. Aguardar conexão

### Usar Chat
1. Selecionar contato
2. Digitar mensagem
3. Pressionar Enter ou clicar Enviar

## 🆘 Problemas Comuns

| Problema | Solução |
|----------|---------|
| Não carrega dados | Atualizar página (F5) |
| WhatsApp desconectado | Gerar novo QR Code |
| Erro ao salvar | Verificar campos obrigatórios |
| Busca não funciona | Limpar filtros |
